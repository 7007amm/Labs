# Лабораторная работа №2: Демонстрация и исправление уязвимостей (OWASP Top 10)

Учебный проект создан исключительно в образовательных целях для локального тестирования.

## Структура проекта
* `lab2_app.py` — локальное веб-приложение на Flask с двумя уязвимостями (SQL Injection и Reflected XSS).
* `lab2_exp.py` — PoC-скрипт для демонстрации эксплуатации уязвимостей на локальном сервере (`127.0.0.1`).
* `fix.diff` — патч, устраняющий обе уязвимости (параметризация SQL-запросов и экранирование HTML).

## Запуск
1. `pip install flask requests`
2. `python lab2_app.py`
3. `python lab2_exp.py`
