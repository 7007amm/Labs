# Лабораторная работа №1: Определение параметров ОС

## Описание проекта
Скрипт на Python для автоматического определения операционной системы и сбора подробных технических характеристик компьютера без установки сторонних пакетов. Результаты сохраняются в структурированном файле system_info.json.

## Используемые модули (Standard Library)
Программа использует исключительно встроенные библиотеки Python:
* platform — для определения ОС, архитектуры, версии ядра и данных процессора.
* os — для подсчета доступных логических ядер процессора.
* sys — для получения информации об интерпретаторе Python и путях к нему.
* json — для структурирования данных и записи итогового JSON-файла.

## Собираемые параметры
Данные в итоговом отчете разделены на три блока:

1. Операционная система (OS):
   * Название ОС, релиз и точная версия сборки.
   * Архитектура разрядности (64bit) и формат файлов (ELF / WindowsPE).
   * Сетевое имя устройства и тип аппаратной платформы.

2. Аппаратная часть (Hardware):
   * Название модели процессора.
   * Количество логических ядер (потоков) CPU.

3. Окружение Python:
   * Версия интерпретатора и используемый компилятор.
   * Полный путь к исполняемому файлу Python в системе.
